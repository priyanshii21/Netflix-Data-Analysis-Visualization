
# Netflix Data Analysis & Visualization

This project analyzes Netflix content using Python, Pandas, Matplotlib, and Seaborn. The analysis focuses on content strategy, user demographics, genres, countries, directors, actors, movie duration, and Netflix's content release trends.

### Key Analysis

* Movies vs TV Shows distribution
* Most popular Netflix genres
* Content released by year
* Top countries producing Netflix content
* Most common content ratings
* Top directors and actors
* Movie duration analysis
* Content added by month and year
* Genre trends across years
* Netflix content distribution across countries

### Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook
* CSV Dataset

### Key Findings

The analysis shows that Netflix has more Movies than TV Shows, Drama and Comedy are among the most common genres, and the United States is a major contributor to Netflix content. The project also explores content growth, audience targeting, and content launch patterns.

This project was created as a data analysis and visualization project to practice Python-based data analytics and extract meaningful insights from real-world data.
